# “ADHD Cognitive Assessment Games – Go/No-Go & N-Back"
To check your physical quick response for determining ADHD thorough some terminal based easy games.


Go/No-Go Task

The Go/No-Go Task is a reaction-control and response-inhibition game designed to measure behavioral performance related to attention and impulsive responding.

In each trial, a visual stimulus such as a letter or shape is presented to the participant. The participant must respond to the Go stimulus and withhold their response when the No-Go stimulus appears.

Task Logic

- Go stimulus: Participant should respond.
- No-Go stimulus: Participant should not respond.
- Commission Error: Responding when a No-Go stimulus appears.
- Omission Error: Failing to respond to a Go stimulus.

Performance Metrics

The game records:

- Correct responses
- Commission errors
- Omission errors
- Response accuracy
- Reaction time

The collected results can be used as experimental measures of response inhibition and attentional performance.





N-Back / Digit Span Task



The N-Back Task is a working-memory game in which digits are presented sequentially. The participant must determine whether the current digit matches the digit presented N positions earlier.

The project supports different difficulty levels, such as 1-Back, 2-Back, and 3-Back, allowing the working-memory demand to be increased progressively.

Task Logic

For example, in a 2-Back task:

"4 → 7 → 4 → 2 → 7"

At the third position:

"Current = 4"
"2 positions back = 4"

Therefore, the correct response is MATCH.

Performance Metrics

The game records:

- Correct responses
- Incorrect responses
- Match accuracy
- False alarms
- Missed matches
- Reaction time
- Average reaction time
- Working-memory score

The basic working-memory score is calculated as:

"Working Memory Score = Correct Responses / Testable Trials"

The task can be used as an experimental measure of working-memory performance and cognitive accuracy.
